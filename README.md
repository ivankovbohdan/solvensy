# Внести зміни в проект

## Встановлення залежностей

```bash
npm install
```

## Запуск проекту локально

```bash
npm start
```

## Збірка проекту

```bash
npm run build
```

## Розгортання на хостингу

1. Виконати команду збірки:

   ```bash
   npm run build
   ```

2. Завантажити вміст папки `dist` на сервер через FTP (наприклад, FileZilla).

3. Переконатися, що всі файли коректно відображаються на сайті.
